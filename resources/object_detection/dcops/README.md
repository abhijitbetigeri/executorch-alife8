# DC-Ops vision model

Deployed DC-Ops vision model for the demo firmware: `dcops_v3_board_ft_ethos-u85-256.pte` (MobileNetV2, 160 px, 16 classes + background, board-camera fine-tuned) with `labels.txt`, `metrics.json` and `export.json`. `dcops_v2_r160_kd_ethos-u85-256.pte` is the earlier student before the board fine-tune.

PyTorch weights, ablations and teachers: https://huggingface.co/abhijitbetigeri/dcops-e8
